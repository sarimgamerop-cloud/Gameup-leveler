# Gameup-leveler
a advanced gamers skill categorizer.

I took the frontend design from my arch desktop, it features the classic oxygen theme paired with candy icons, the sweet theme on konsole and the jetbrainsmono nerd fon, i wanted my actual desktop inside the browser, thats why the quiz is a "program" you run from a terminal. the idea and the direction of classic desktop feel is the reason for implementing the draggable icon that snaps to a grid, the taskbar, the konsole style window with the three buttons, the prompt, history with arrow keys, the 20 questions that end on a 2d plane and not just one label.
